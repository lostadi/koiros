# Koiros 1.8

**Lee Ostadi’s evolving computational wallpaper.**

Download **Koiros-1.8.apk**, install it on Android 8.0 or newer, open Koiros,
and choose **Set wallpaper**. Live-wallpaper support is required. Root and
Ostadix are not required. Slow defaults: 0.18× drift and shape evolution,
0.25× color drift; adjust each independently down to 0.02×.

Ten evolving forms, one to nine creatures, independent Life fields, coupled
chaos, gradual neon gradients, shared currents, soft collisions, and optional
tap ripples. Upgrades from Koi / Life preserve the package and signing identity.

Created by **Lee Daghlar Ostadi**, with source adapted from **Artificial Koi**
by **Studio Coldstream / Mathew Molt** and **GoL Screensaver** by **Harold Martin**.
The combined app is GPL-3.0-or-later; upstream notices are preserved in source
and in the app. [Full credits](https://github.com/lostadi/koiros/blob/v1.8/docs/CREDITS.md).

## Verification and source

- Two clean Android/Termux builds produced byte-identical unsigned **and signed** APKs.
- Both builds passed all six model test suites (526,995 assertions per build).
- Native Android Canvas checks passed against this exact signed APK through Ostadix, covering all ten forms, simulation clocks, slow evolution, and touch behavior.
- The separate Linux CI recipe verifies two clean unsigned builds with its pinned reference toolchain. Different toolchains are not assumed to produce identical bytes.
- No multi-device hardware testing is claimed; other devices and manufacturers may render or expose wallpaper options differently.

`Koiros-1.8-source.zip` contains the corresponding source, licenses, build
scripts, and installation instructions. `Koiros-1.8-unsigned.apk` is a build
comparison artifact, **not the install download**. `SHA256SUMS`,
`build-metadata.json`, `reproducibility.json`, and `render-report.json` record
the artifact checksums, source/tool fingerprints, and actual verification.
